Política de Privacidad — aqui esta el como FunkBot maneja la información necesaria para funcionar dentro de Discord.

Última actualización · 22 de septiembre de 2026

01 Recopilación de datos

FunkBot no recopila ni almacena datos personales de sus usuarios.

Para funcionar correctamente, FunkBot puede recibir y procesar temporalmente información proporcionada por Discord durante la ejecución de sus funciones, como:

  • Identificadores de usuarios.
  • Identificadores de servidores.
  • Identificadores de canales.
  • Información de comandos enviados a FunkBot.
  • Información necesaria para gestionar la reproducción de música.

Esta información se utiliza únicamente cuando es necesaria para ejecutar las funciones solicitadas y no se almacena permanentemente en una base de datos de FunkBot.

02 Uso de la información

La información recibida temporalmente desde Discord se utiliza exclusivamente para permitir el funcionamiento de FunkBot.

Por ejemplo, puede utilizarse para:

  • Identificar dónde debe ejecutarse un comando.
  • Gestionar canales de voz.
  • Reproducir, pausar o cambiar música.
  • Administrar temporalmente una cola de reproducción.
  • Responder a comandos enviados por los usuarios.

Esta información no se utiliza para publicidad, elaboración de perfiles de usuarios ni otros fines ajenos al funcionamiento de FunkBot.

03 Almacenamiento de datos

FunkBot no mantiene una base de datos con información personal de sus usuarios.

La información necesaria para determinadas funciones puede mantenerse temporalmente en memoria mientras FunkBot se encuentra funcionando.

Por ejemplo, una cola de reproducción puede existir temporalmente mientras se utiliza el Bot en un servidor.

Esta información temporal puede desaparecer cuando deja de ser necesaria, cuando finaliza la sesión correspondiente o cuando el servicio se reinicia.

04 Mensajes y conversaciones

FunkBot no almacena conversaciones de los usuarios de Discord.

El Bot puede procesar comandos o información enviada directamente a sus funciones cuando sea necesario para responder a una solicitud.

FunkBot no utiliza conversaciones de los servidores para crear perfiles de usuarios ni para fines publicitarios.

05 Compartición y venta de datos

FunkBot no vende, comercializa ni proporciona bases de datos personales de sus usuarios a terceros.

Algunas funciones pueden depender de servicios externos, como Discord o proveedores utilizados para localizar o reproducir contenido musical.

La información procesada directamente por dichos servicios está sujeta a sus respectivas políticas de privacidad.

06 Eliminación de datos

Debido a que FunkBot no mantiene una base de datos permanente con información personal de sus usuarios, normalmente no existen datos personales almacenados por FunkBot que sea necesario solicitar eliminar.

Si consideras que existe información relacionada contigo o con tu servidor que debería ser eliminada, puedes comunicarte mediante los medios indicados en la sección de contacto.

07 Seguridad

Aunque FunkBot no almacena datos personales de usuarios de manera permanente, se toman medidas razonables para proteger el funcionamiento del servicio y evitar accesos no autorizados a su infraestructura.

08 Servicios de terceros

FunkBot funciona dentro de Discord y puede depender de otros servicios externos para proporcionar determinadas funciones, especialmente aquellas relacionadas con música.

FunkBot no controla las políticas de privacidad, disponibilidad o funcionamiento de estos servicios externos.

09 Cambios en esta Política de Privacidad

Esta Política de Privacidad puede actualizarse si las funciones de FunkBot cambian o si en el futuro se modifica la manera en que el Bot procesa información.

Si FunkBot comienza a almacenar nuevos tipos de información de manera permanente, esta política deberá actualizarse para reflejar dichos cambios.

La fecha de la última actualización aparecerá al principio de este documento.
